Option 1: Image Dataset Folder (Drag & drop the main folder)
Place each class in its own subfolder. The subfolder names automatically become the Target Classes, and images are resized locally in your browser to 32×32:
my_image_dataset/ <-- Drag & drop this folder! ├── Benign/ <-- Target Class 0 │ ├── sample_01.png │ └── sample_02.png ├── Ransomware/ <-- Target Class 1 │ ├── mal_01.png │ └── mal_02.png └── Trojan/ <-- Target Class 2 └── troj_01.jpg
Option 2: Tabular CSV File (Drag & drop any .csv)
Provide a standard header row where columns represent features and one column represents the target class label:
entropy,import_count,is_packed,malware_family 4.82,85,0,Benign 7.45,32,1,Ransomware 6.19,64,1,Trojan 5.91,72,0,Spyware
